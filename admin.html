Why new requests only appeared on the client's device:
When clients submit requests from other devices, their browser attempts to write to Firebase (project: matnix-studios). If the Firebase Console has default locked rules, Google's servers reject the write with 403 PERMISSION_DENIED, causing the request to fall back into that device's local browser cache.

1. Publish Firestore Rules

Open Firebase Console and publish read/write rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
Open Firebase Rules

2. Publish Realtime DB Rules

Open Realtime Database and set read/write to true:

{
  "rules": {
    ".read": true,
    ".write": true
  }
}
